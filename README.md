# Namira — Next Level Love Experience

## Open it
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Double-click `index.html` or use VS Code Live Server.
4. For GitHub Pages, upload the whole project and enable Pages from the `main` branch / root.

## Add your real photos
Open `assets/photos/`.
Replace:
- photo-1.svg
- photo-2.svg
- photo-3.svg
- photo-4.svg

You can use JPG/PNG files, but then update the four `<img src="...">` paths in `index.html` accordingly.

## Music
The current button uses a tiny browser-generated ambient tone, so the project works without an audio file.
If you want an actual song, put an audio file in `assets/music/` and change the music section in `script.js`.
